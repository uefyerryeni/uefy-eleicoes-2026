# UEFY Eleições 2026

Ferramenta da Uefyerryeni para acompanhar a apuração oficial e preparar publicações para o X.

## Mapas
Os arquivos em `assets/maps/` usam malhas territoriais derivadas de dados públicos do IBGE:
- `br-estados.geojson`: Unidades da Federação.
- `rn-municipios.geojson`: municípios do Rio Grande do Norte.

A interface usa os mesmos GeoJSON tanto na visualização do site quanto na arte quadrada gerada para compartilhamento.

## Dados eleitorais
O projeto foi preparado para os arquivos de divulgação de resultados do TSE e inclui um modo local de demonstração para testes antes da apuração real.
